# Simulador de Investimentos em FIIs

## Sobre o projeto

Este projeto foi criado como parte de um desafio da DIO (Digital Innovation One).

O objetivo era colocar em prática conhecimentos sobre organização de dados e simulação de investimentos em Fundos de Investimento Imobiliário (FIIs).

A ideia é usar uma planilha para fazer simulações de investimentos. Assim, é possível ver como valores diferentes investidos podem crescer ao longo do tempo.

## Objetivos

* Simular investimentos em FIIs;

* Organizar informações financeiras em uma planilha;

* Aplicar conceitos de investimentos e renda passiva;

* Utilizar fórmulas para cálculos automáticos;

* Apresentar resultados de forma organizada e fácil de entender.

## Ferramentas utilizadas

* Microsoft Excel;

* GitHub;

* Planilhas e fórmulas financeiras.

## Estrutura do projeto

O projeto contém:

* `Simulador investimentos.xlsx` — planilha utilizada para realizar as simulações;

* `README.md` — documentação do projeto.

## Como utilizar

1. Baixe ou abra o arquivo `Simulador investimentos.xlsx`.

2. Preencha os campos solicitados na planilha.

3. Informe os valores relacionados ao investimento.

4. Confira os resultados calculados automaticamente.

5. Utilize os resultados para analisar diferentes cenários de investimento.

## Aprendizados

* Organização de informações em planilhas;

* Utilização de fórmulas no Excel;

* Simulação de cenários financeiros;

* Interpretação de resultados;

* Documentação e publicação de projetos no GitHub.
